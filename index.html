1과목 · 로봇드라이버설계

액추에이터(모터)와 그 구동 회로. 전기기사의 전기기기와 회로이론에 해당합니다.

1-1. DC 모터 기본식

전압식 V = R·i + L·di/dt + e (e = Ke·ω 역기전력) 토크식 T = Kt·i (SI 단위에서 Kt = Ke) 정상상태 ω = (V − R·T/Kt) / Ke → 속도-토크 직선 무부하속도 ω0 = V/Ke 기동(구속)전류 Is = V/R 구속토크 Ts = Kt·V/R 최대 기계출력: T = Ts/2, ω = ω0/2 일 때 Pmax = Ts·ω0/4
  • 속도는 인가 전압에, 토크는 전류에 비례합니다.
  • 기동 순간엔 ω=0이라 역기전력이 0이고, 전류가 V/R로 가장 큽니다. 그래서 소프트스타트나 전류 제한이 필요합니다.
헷갈림 주의 부하가 커지면 속도는 떨어지고 전류는 올라갑니다. 문제에서 "부하 증가 시 전류는?"이라고 물으면 증가가 답입니다.

1-2. 모터 종류 비교

종류특징시험 포인트
브러시 DC구조 간단, 제어 쉬움, 브러시 마모속도 ∝ 전압, 토크 ∝ 전류
BLDC전자식 정류, 수명 길고 효율 높음홀센서 3개, 6스텝(120° 통전): 한 번에 2상 통전
PMSM / AC서보정현파 구동, 엔코더 피드백FOC: Clarke(abc→αβ) → Park(αβ→dq)
스테핑오픈루프 위치제어, 탈조 위험1.8° = 200스텝/회전, 마이크로스텝은 스텝 수 × 분할수
스테핑 1회전 펄스 = (360° / 스텝각) × 마이크로스텝 분할수 예) 1.8°, 1/16 → 200 × 16 = 3200 펄스

1-3. 서보 드라이브 제어 루프

  • 안쪽부터 전류(토크) 루프 → 속도 루프 → 위치 루프. 안쪽 루프일수록 대역폭이 넓고(빠르고) 주기가 짧습니다.
  • 튜닝 순서도 안쪽부터: 전류 → 속도 → 위치.
  • 제어 모드: 위치 모드(펄스열/필드버스), 속도 모드, 토크 모드.

1-4. H브리지와 PWM

평균 출력전압 Vavg = D × Vs (D = Ton / T, 듀티비) PWM 주파수 f = 1 / T
  • H브리지: 스위치 4개로 정·역회전과 제동을 합니다. 대각선 두 스위치를 켜면 한 방향으로 돕니다.
  • 슛스루(shoot-through): 같은 레그의 상·하단이 동시에 켜져 전원이 단락되는 현상. 이걸 막는 게 데드타임입니다.
  • 프리휠링(환류) 다이오드: 스위치가 꺼질 때 인덕턴스 전류가 흐를 길을 만들어 역기전압 스파이크를 막습니다.
  • 부트스트랩 회로: 하이사이드 N채널 MOSFET은 게이트를 소스보다 높여야 해서, 커패시터로 승압된 게이트 전원을 만듭니다.
  • PWM 주파수를 가청 대역(약 20kHz) 위로 올리면 소음이 줄지만 스위칭 손실이 늘어납니다.

1-5. 전력 반도체

소자구동용도
BJT전류 구동(베이스 전류)소신호, 저전력
MOSFET전압 구동(게이트), 고속저·중전압 모터 드라이버의 주력
IGBT전압 구동, 고전압·대전류산업용 서보, 인버터(상대적으로 저주파)
MOSFET 도통손실 P = I² × Rds(on) 예) 5A, 20mΩ → 25 × 0.02 = 0.5 W 총손실 = 도통손실 + 스위칭손실(∝ 스위칭 주파수)

1-6. 감속기와 관성

감속비 N (모터 N회전 → 출력 1회전) 출력 토크 = 모터 토크 × N × 효율η 출력 속도 = 모터 속도 / N 부하 관성의 모터축 환산 J' = J_load / N²
  • 관성비(부하 환산 관성 / 모터 관성)가 크면 응답이 나빠지고 진동이 생깁니다. 감속기를 쓰면 N²배로 줄어듭니다.
  • 하모닉 드라이브: 백래시가 거의 없고 감속비가 커서 협동로봇 관절에 많이 씁니다.

1-7. 제동과 보호

  • 회생 에너지: 감속할 때 모터가 발전기가 되어 DC링크 전압이 올라갑니다. 제동(회생)저항으로 열로 소모시킵니다.
  • 과전류, 과전압, 저전압, 과열 보호. 전류 검출은 션트저항이나 홀 전류센서로 합니다.
  • 전자 브레이크: 수직축은 전원이 꺼지면 잡아주는 무여자 작동형을 씁니다.

1-8. 회로이론 단골

RC 시정수 τ = R·C RL 시정수 τ = L/R 1τ 후 충전 약 63.2%, 5τ 후 약 99% (정상상태로 봄) 전력 P = V·I = I²R = V²/R

2과목 · 로봇제어부설계

MCU 하드웨어, 주변장치, 통신, 임베디드 C, 제어 알고리즘.

2-1. MCU 구조

  • CPU 코어 + Flash(프로그램) + SRAM(변수) + 주변장치(GPIO, 타이머, ADC, 통신).
  • 하버드 구조: 명령 버스와 데이터 버스가 분리되어 동시에 접근할 수 있습니다. 폰 노이만: 하나의 버스를 공유합니다.
  • 클럭: 외부 크리스털 → PLL로 체배 → 시스템 클럭 → 버스별 분주.
  • GPIO 출력: 푸시풀(High/Low를 직접 구동), 오픈드레인(Low만 구동하므로 풀업 필요, I2C에 사용).

2-2. 타이머와 PWM 계산

타이머 주파수 f = f_clk / ((PSC+1) × (ARR+1)) 듀티비 D = CCR / (ARR+1) 예) 72MHz, PSC=71, ARR=999 → 72,000,000 / (72×1000) = 1 kHz CCR=250 → 듀티 25%
헷갈림 주의 레지스터 값에는 +1을 붙입니다. PSC=71이면 72분주예요.

2-3. ADC

1 LSB = Vref / 2^n 측정 전압 = (ADC값 / 2^n) × Vref (책에 따라 2^n − 1로 나누기도 함) 예) 12비트, 3.3V → 1 LSB ≈ 0.806 mV, 값 2048 → 약 1.65 V
  • 방식: SAR(축차비교형, MCU 내장 주력), 플래시형(가장 빠름), 시그마-델타(고분해능, 느림).
  • 샘플링 정리: 샘플링 주파수 > 2 × 신호 최고 주파수. 지키지 않으면 앨리어싱이 생깁니다.

2-4. 인터럽트, DMA, 워치독

  • 폴링: CPU가 계속 확인. 인터럽트: 사건이 생길 때만 ISR 실행. 응답이 빠르고 CPU가 덜 바쁩니다.
  • ISR은 짧게 작성하고, 메인 루프와 공유하는 변수는 volatile로 선언합니다(컴파일러 최적화 방지).
  • NVIC: 인터럽트 우선순위, 중첩(선점)을 관리합니다.
  • DMA: CPU 개입 없이 주변장치와 메모리 간에 데이터를 옮깁니다(ADC 연속 변환, UART 수신).
  • 워치독 타이머: 정해진 시간 안에 카운터를 리셋(킥)하지 않으면 MCU를 강제로 리셋합니다. 폭주 대비용입니다.
  • BOR(Brown-out reset): 전원 전압이 떨어지면 리셋합니다.

2-5. 임베디드 C 비트 연산

비트 n 세트 REG |= (1 << n); 비트 n 클리어 REG &= ~(1 << n); 비트 n 토글 REG ^= (1 << n); 비트 n 검사 if (REG & (1 << n)) { ... }
  • 레지스터 접근: *(volatile uint32_t*)주소, 구조체로 레지스터 맵을 정의합니다.
  • 고정 크기 정수형: uint8_t, int16_t, uint32_t (stdint.h).

2-6. 통신 방식 비교

방식선특징
UARTTX, RX (+GND)비동기, 클럭선 없음, 양쪽 보레이트가 같아야 함. 8N1 = 시작1+데이터8+정지1 = 10비트
SPISCLK, MOSI, MISO, CS(SS)동기식, 전이중, 빠름, 마스터 1 : 슬레이브 N (CS선이 슬레이브마다 필요)
I2CSDA, SCL동기식, 반이중, 오픈드레인이라 풀업저항 필수, 7비트 주소, ACK
CANCAN_H, CAN_L차동, 멀티마스터, 양 끝 120Ω 종단, ID가 낮을수록 우선(우성=0)

2-7. PID 제어

u(t) = Kp·e + Ki·∫e dt + Kd·de/dt 이산형 u[k] = Kp·e[k] + Ki·Ts·Σe + Kd·(e[k] − e[k−1])/Ts
  • P: 응답이 빨라지지만 정상상태 오차가 남고, 너무 크면 진동합니다.
  • I: 정상상태 오차를 없앱니다. 너무 크면 오버슈트가 생기고, 포화 시 와인드업이 일어납니다. 그래서 안티와인드업을 씁니다.
  • D: 오버슈트를 줄이고 감쇠를 늘리지만, 노이즈에 민감하니 저역통과필터와 같이 씁니다.

2-8. 모션 프로파일

사다리꼴: 가속 시간 ta = Vmax / a, 가속 구간 거리 = Vmax² / (2a) 예) Vmax 1 m/s, a 2 m/s² → ta = 0.5 s, 거리 0.25 m
  • 사다리꼴: 가속도가 계단처럼 바뀌어 저크(jerk)가 무한대가 되고, 충격과 진동이 생깁니다.
  • S-커브: 저크를 제한해 가속도가 연속으로 바뀌므로 부드럽습니다. 대신 이동 시간이 조금 깁니다.

3과목 · 로봇 센서 및 신호처리

센서 원리와 아날로그·디지털 신호처리 회로.

3-1. 엔코더

4체배 분해능 = PPR × 4 (카운트/회전) 각도 분해능 = 360° / (PPR × 4) 예) 1000 PPR → 4000 카운트, 0.09°
  • 증분형(인크리멘털): A상, B상이 90° 위상차. 어느 쪽이 앞서는지로 회전 방향을 판별하고, Z상은 1회전에 1펄스(원점)입니다. 전원이 꺼지면 위치를 잃습니다.
  • 절대형(앱솔루트): 위치를 코드(그레이 코드 등)로 출력해 전원을 껐다 켜도 위치를 압니다. 멀티턴은 배터리나 기어로 회전수까지 기억합니다.
  • 레졸버: 회전 변압기 원리라 진동과 열에 강합니다.
속도 측정법방법유리한 구간
M법일정 시간 동안 펄스 개수를 셈고속
T법펄스 사이 시간(주기)을 잼저속
M/T법둘을 결합전 구간

3-2. 거리·근접·광센서

초음파 거리 d = v × t / 2 (v ≈ 340 m/s, t는 왕복 시간) 예) 6 ms → 340 × 0.006 / 2 = 1.02 m
  • 유도형 근접센서는 금속만 감지합니다. 정전용량형은 플라스틱, 물 같은 비금속도 감지합니다.
  • 광전센서: 투과형(가장 확실), 회귀반사형, 확산반사형.
  • LiDAR, ToF: 빛의 비행시간으로 거리를 잽니다.
  • NPN 출력은 싱크형이라 부하를 +V와 출력 사이에 겁니다. PNP 출력은 소스형이라 부하를 출력과 0V 사이에 겁니다.

3-3. 힘·토크와 스트레인게이지

게이지율 GF = (ΔR/R) / ε 쿼터 브리지 출력 ≈ Vex × GF × ε / 4
  • 미세한 저항 변화를 전압으로 바꾸는 데 휘트스톤 브리지를 씁니다. 출력이 수 mV라 계측 증폭기로 키웁니다.
  • 하프/풀 브리지를 쓰면 감도가 올라가고 온도 보상이 됩니다.

3-4. IMU

  • 가속도계: 중력 방향으로 기울기를 알 수 있지만 진동 노이즈에 약합니다.
  • 자이로: 각속도를 적분해 각도를 구하면 드리프트가 쌓입니다.
  • 상보필터: 자이로는 고역, 가속도계는 저역을 취해 합칩니다. 칼만필터: 확률 모델로 최적 추정합니다.
  • 지자기 센서는 요(yaw) 보정에 쓰지만 주변 자기장에 민감합니다.

3-5. OP앰프 회로

반전 증폭기 Av = −Rf / Rin 비반전 증폭기 Av = 1 + Rf / Rin 전압 팔로워 Av = 1 (임피던스 버퍼) 차동 증폭기 Vout = (Rf/Rin)(V2 − V1) (저항 정합 시) 데시벨 dB = 20·log10(Vout/Vin)
  • 계측 증폭기: 입력 임피던스가 매우 높고 CMRR이 높아 브리지 센서의 작은 차동 신호 증폭에 씁니다.
  • 비교기와 슈미트 트리거: 히스테리시스를 줘서 노이즈로 출력이 떨리는(채터링) 것을 막습니다.
  • 이상적 OP앰프: 입력 임피던스 ∞, 출력 임피던스 0, 개방이득 ∞, 가상 단락.

3-6. 필터와 샘플링

RC 1차 필터 차단주파수 fc = 1 / (2πRC) 예) 1kΩ, 0.1µF → 1 / (2π × 10⁻⁴) ≈ 1.59 kHz 차단주파수에서 이득 = 1/√2 ≈ 0.707 = −3 dB 1차 필터 감쇠 기울기 = −20 dB/decade
  • LPF는 고주파 노이즈를 제거하고, HPF는 DC와 저주파 드리프트를 제거합니다.
  • ADC 앞의 안티앨리어싱 필터는 LPF입니다.
  • 디지털 필터: 이동평균(간단), FIR(선형 위상, 항상 안정), IIR(적은 연산, 피드백이 있어 불안정할 수 있음).

3-7. 노이즈 대책과 신호 전송

  • 디커플링 커패시터(0.1µF)는 IC 전원핀 가까이에 둡니다.
  • 트위스트 페어, 실드 케이블(실드는 한쪽 접지가 기본), 신호선과 동력선 분리 배선.
  • 포토커플러로 절연해 접지 루프와 서지를 차단합니다.
  • 4~20mA 전류 루프: 장거리에서도 전압 강하 영향이 없고, 4mA를 0점으로 써서 0mA면 단선으로 판단합니다.

4과목 · 로봇시스템 통합 및 시험평가

전원, 신뢰성, 안전, 시험 방법. 계산 몇 개와 외울 것 위주입니다.

4-1. 전원 설계

리니어(LDO) 발열 P = (Vin − Vout) × I, 효율 ≈ Vout / Vin 예) 12V→5V, 1A → 7 W 발열, 효율 약 41.7% 벅(강압) 컨버터 Vout = D × Vin (이상적) 부스트(승압) Vout = Vin / (1 − D) 배터리 사용시간 ≈ 용량(mAh) / 소비전류(mA) 예) 2000/500 = 4 h
  • LDO는 노이즈가 적고 간단하지만, 전압 차가 크면 발열이 큽니다. 스위칭 레귤레이터는 효율이 높지만 스위칭 노이즈가 있습니다.
  • 리튬이온 셀: 공칭 3.6~3.7V, 만충 4.2V. 직렬 셀 수 S, 병렬 P (예: 6S → 공칭 약 22.2V).
  • BMS: 과충전·과방전·과전류 보호, 셀 밸런싱.
  • 모터 전원과 로직 전원을 분리하거나 필터를 넣어 모터 노이즈가 MCU로 가지 않게 합니다.

4-2. 신뢰성

신뢰도 R(t) = e^(−λt) MTBF = 1 / λ 예) λ = 0.001/h → 1000 h 직렬 시스템 R = R1 × R2 × ... 예) 0.9 × 0.95 = 0.855 병렬 시스템 R = 1 − (1−R1)(1−R2) 예) 0.9, 0.9 → 0.99 가용도 A = MTBF / (MTBF + MTTR) 예) 900/(900+100) = 0.9 FMEA RPN = 심각도 S × 발생도 O × 검출도 D
  • 욕조 곡선: 초기고장기(고장률 감소, 번인으로 걸러냄) → 우발고장기(고장률 일정) → 마모고장기(고장률 증가).
  • FTA는 결과(톱 이벤트)에서 원인으로 내려가는 하향식, FMEA는 부품 고장 모드에서 영향을 따지는 상향식입니다.

4-3. 로봇 성능 지표

  • 반복정밀도(repeatability): 같은 지령 위치에 여러 번 갔을 때 흩어지는 정도. 산업용 로봇 사양서에 주로 적힙니다(예: ±0.02mm).
  • 정확도(accuracy): 지령 위치와 실제 도달 위치의 차이. 보통 반복정밀도보다 값이 큽니다(나쁩니다).
  • 성능 시험 표준: ISO 9283. 그 밖에 가반하중, 작업영역, 자유도, 최대속도.

4-4. 안전 표준

표준내용
ISO 12100기계 안전 일반원칙, 위험성 평가
ISO 10218-1/-2산업용 로봇 안전 (1: 로봇, 2: 로봇 시스템·통합)
ISO/TS 15066협동로봇. 신체 부위별 허용 힘·압력
ISO 13849-1제어 시스템 안전 관련부, 성능 수준 PL a~e

  • 정지 카테고리 0: 즉시 동력 차단(비제어 정지). 1: 제어 정지 후 동력 차단. 2: 제어 정지 후 동력 유지.
  • 협동 운전 4가지: 안전 등급 감시 정지, 핸드 가이딩, 속도·간격 감시, 동력·힘 제한.
  • 비상정지 버튼은 적색 버섯형에 황색 배경, 수동 복귀형입니다.

4-5. 환경·EMC·IP 등급

  • IP 등급 IPXY: 첫째 자리 X는 고형물·먼지(0~6), 둘째 자리 Y는 물(0~9). IP67 = 완전 방진 + 일시 침수.
  • EMC = EMI + EMS. EMI는 내가 내보내는 노이즈(방사·전도 방출), EMS는 외부 노이즈를 견디는 능력(내성). ESD, 서지, EFT 시험이 EMS에 속합니다.
  • 환경시험: 고온·저온, 온습도, 진동, 충격, 염수분무.

4-6. 통합과 시험 절차

  • V-모델: 요구사항 ↔ 인수시험, 시스템 설계 ↔ 시스템시험, 상세 설계 ↔ 통합시험, 구현 ↔ 단위시험.
  • 검증(Verification): 명세대로 제대로 만들었는가. 확인(Validation): 사용자가 원하는 올바른 제품을 만들었는가.
  • PCB: 전원·접지 패턴은 굵게, 접지 면(ground plane), 대전류와 신호 영역 분리, 발열 소자 방열.
  • 배선: 케이블 굴곡 반경, 케이블베어, 커넥터 체결 확인, 와이어 색상과 번호 표기.

코드로 미리 익혀 둘 것

  • GPIO 입출력, 내부 풀업 설정, 스위치 디바운싱(약 20ms)
  • 타이머 인터럽트로 일정 주기 작업 만들기
  • PWM으로 LED 밝기와 DC모터 속도 조절, 정·역회전(H브리지 입력 2개)

  • UART로 값 출력(디버깅에도 필수)
  • FND·LCD 표시, 스테핑모터 상 여자 순서(공개문제에 나오는 경우)
